## Selected projects

### Camera–LiDAR Perception with ROS 2
Built an inference pipeline combining **YOLOv8n**, camera–LiDAR fusion, vehicle-relative localization, and **RViz** visualization. Includes a demonstration recording, technical report, contribution summary, and result bags with **1,305 timestamped output arrays** at 0.25× replay.

[Demo and reproduction guide](https://github.com/VioletGo319/ros2-perception#start-here) · **Python / ROS 2 / OpenCV / YOLO**

### Shopee Product Matching — Kaggle competition
Contributed to a team solution combining **Swin Transformer, NFNet, ArcFace, TF-IDF, and perceptual hashes** to retrieve matching product listings. Team result: **silver medal, top 4%**. The repository documents the archived inference notebook and its external dependencies.

[Notebook and pipeline](https://github.com/VioletGo319/Shopee-Kaggle-Competion_Python) · **PyTorch / computer vision / metric learning / retrieval**

### Reinforcement Learning Strategy Evaluation
Contributed to an NYU course project comparing **PPO, A2C, and DDPG** through rolling training and validation windows, selecting models by validation Sharpe ratio before the next trading period.

[Experiment and report](https://github.com/VioletGo319/Reinforcement_Learning_strategy) · **Python / reinforcement learning / time-series evaluation**

### Cervical Cancer Risk Modeling
Collaborative R analysis of **858 patient records**, covering missing-data handling, exploratory analysis, **LASSO** feature selection, and model comparisons across sampling ratios.

[Analysis and report](https://github.com/VioletGo319/Cervical-Cancer-Classification) · **R / statistical modeling / healthcare data**
